## Agent skills

### Issue tracker

Задачи и PRD проекта ведутся в GitHub Issues. Подробности см. в `docs/agents/issue-tracker.md`.

### Triage labels

В репозитории используется стандартный набор из пяти triage-меток. Подробности см. в `docs/agents/triage-labels.md`.

### Domain docs

В репозитории используется single-context структура доменной документации. Правила описаны в `docs/agents/domain.md`.
