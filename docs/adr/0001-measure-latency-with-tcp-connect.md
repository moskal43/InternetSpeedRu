# Измерять latency через TCP connection probes

InternetSpeedRu определяет latency как медиану трёх измерений времени установки TCP-соединения с фактически выбранным Iperf3-портом непосредственно перед speed test. Единый TCP-метод выбран вместо ICMP с fallback, потому что ICMP поддерживается не всеми серверами, а смешение методов сделало бы исторические значения несопоставимыми; packet loss поэтому не входит в `v0.1`.
