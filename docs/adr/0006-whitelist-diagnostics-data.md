# Формировать diagnostics по whitelist

Diagnostics InternetSpeedRu содержат только версию интеграции, режим и интервал, публичные данные выбранного сервера, источник и возраст каталога, времена последней попытки и последнего успеха, статус и нормализованный код ошибки. Local/public IP пользователя, имя интерфейса, DNS-результаты, сырые Iperf3 JSON-ответы и история замеров исключаются, поскольку диагностическая ценность не оправдывает риск раскрытия сетевых данных.
