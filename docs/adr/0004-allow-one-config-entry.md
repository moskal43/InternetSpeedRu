# Разрешить один config entry

В `v0.1` InternetSpeedRu допускает ровно один config entry, который предоставляет единый набор метрик и переключается между ручным выбором и Auto через Options Flow. Это исключает конкурирующие тяжёлые замеры и упрощает стабильную идентичность сущностей; параллельное сравнение нескольких серверов сознательно оставлено за пределами первой версии.
