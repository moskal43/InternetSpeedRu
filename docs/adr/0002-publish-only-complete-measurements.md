# Публиковать только полные замеры соединения

Новые latency, download и upload публикуются как один атомарный замер только после успешного завершения обеих Iperf3-фаз на одном сервере и порту. Автоматическая смена порта или сервера допускается только при ошибке до начала передачи данных; сбой уже начавшейся download/upload-фазы завершает попытку без нового тяжёлого теста. InternetSpeedRu сохраняет предыдущий полный результат и отражает сбой через статус, сознательно отказываясь от частичных данных ради сопоставимой истории.
