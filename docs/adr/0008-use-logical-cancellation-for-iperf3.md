# Использовать логическую отмену Iperf3-теста

InternetSpeedRu запускает блокирующий `iperf3==0.1.11` adapter в executor и при unload логически отменяет операцию, не публикуя её поздний результат. Библиотека вызывает `libiperf.iperf_run_client()` без API физической отмены, поэтому уже начатая 10-секундная фаза может завершиться в executor; subprocess или отдельный process worker ради немедленного завершения в `v0.1` не используются.
