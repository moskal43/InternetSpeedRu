# Использовать цепочку валидированных каталогов

InternetSpeedRu загружает upstream `list.yml` только во время работы интеграции, обновляет его не чаще раза в 24 часа и использует только после полной валидации. Полный upstream-каталог не commit'ится и не входит в HACS release; cache создаётся локально в Home Assistant пользователя, а встроенный fallback состоит из небольшого независимо поддерживаемого набора серверов. Источники выбираются в порядке «новый удалённый каталог → последняя валидная закэшированная версия → встроенный каталог релиза»; невалидный ответ не затирает cache, а замер не ожидает GitHub при наличии валидного локального источника.
