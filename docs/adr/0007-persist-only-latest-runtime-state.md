# Сохранять только последнее runtime-состояние

InternetSpeedRu сохраняет между перезапусками последний полный успешный замер и его сервер, актуальную точку отсчёта следующего автоматического запуска, времена последней попытки и успеха, последний статус и нормализованный код ошибки. Успешный ручной замер переносит следующую автоматическую попытку на выбранный интервал, а неудачный — не меняет расписание. Entities восстанавливаются сразу, а история не дублируется внутри интеграции, поскольку за неё отвечает Home Assistant Recorder.
