# Triage-метки

Skills используют пять канонических triage-ролей. Этот файл сопоставляет роли с фактическими строковыми значениями меток в трекере задач репозитория.

| Метка в mattpocock/skills | Метка в нашем трекере | Назначение |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | Задачу должен оценить сопровождающий проекта |
| `needs-info` | `needs-info` | Ожидается дополнительная информация от автора |
| `ready-for-agent` | `ready-for-agent` | Задача полностью описана и готова для автономного агента |
| `ready-for-human` | `ready-for-human` | Для реализации требуется человек |
| `wontfix` | `wontfix` | Задача не будет реализована |

Когда skill упоминает роль, например просит применить метку для готовой агенту задачи, использовать соответствующее строковое значение из таблицы.

Чтобы перейти на другую систему наименований, изменить правый столбец таблицы.
