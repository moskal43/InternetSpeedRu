# InternetSpeedRu

Доменный словарь проекта InternetSpeedRu.

## Language

**InternetSpeedRu**:
Каноническое имя продукта и интеграции Home Assistant, разрабатываемой в этом репозитории.

**Замер соединения**:
Атомарный результат единичного измерения download, upload и latency между устройством с Home Assistant и одним выбранным Iperf3-сервером в России. Результат считается новым только после успешного завершения обеих Iperf3-фаз.
_Avoid_: Универсальная скорость интернета, скорость тарифа, скорость Wi-Fi, скорость LAN

**Latency**:
Медиана трёх измерений времени установки TCP-соединения с фактически выбранным Iperf3-портом непосредственно перед замером соединения.
_Avoid_: ICMP ping, среднее время отклика, packet loss, RTT под нагрузкой

**Каталог серверов**:
Единственный допустимый в `v0.1` набор российских Iperf3-серверов с известными городом, провайдером, адресом и портами; состоит из удалённых данных и локальной резервной копии.
_Avoid_: Произвольный сервер, пользовательский hostname, пользовательский IP

**Автоматический выбор**:
Выбор и закрепление доступного сервера каталога с наименьшей измеренной latency; географическая близость может лишь сократить список кандидатов или разрешить равенство результатов. При включённом Auto первый замер после истечения 24 часов начинается с нового ранжирования; перевыбор также выполняется немедленно после недоступности закреплённого сервера. Работающий сервер заменяется только кандидатом, который быстрее не менее чем на 5 мс и 20%.
_Avoid_: Географически ближайший сервер, сервер с наибольшей измеренной пропускной способностью

**Ручной выбор**:
Закрепление конкретного сервера каталога пользователем. При недоступности всех портов выбранного сервера замер завершается ошибкой и не переключается на другой сервер без ведома пользователя.
_Avoid_: Автоматический failover на другой сервер
